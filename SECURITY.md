# Security Policy

## Supported Versions

Security fixes will be applied to the current development version and, once stable releases are available, the supported versions will be documented here.

## Reporting a Vulnerability

Please do not report security vulnerabilities through public GitHub issues.

For repositories with private vulnerability reporting enabled, please use GitHub's "Report a vulnerability" option in the repository's Security section. This allows security issues to be disclosed privately to the maintainers.

When reporting a vulnerability, please provide as much useful information as possible, including the affected component, steps to reproduce the issue, its potential impact, and any possible mitigation or fix you have identified.

Security reports will be reviewed as soon as reasonably possible. Reports that are confirmed will be investigated and addressed according to their severity and impact. Where appropriate, fixes will be released before details of the vulnerability are publicly disclosed.

Thank you for helping keep Project-Aethra safe.
